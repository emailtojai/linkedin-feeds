# X (Twitter) Guidelines

Platform constraints and style rules for the X Writer.

## Character limits

- **Standard post: 280 characters.** Write to this limit by default — it's what every reader sees and what forces sharp writing.
- X Premium allows longer posts, but assume **280** unless the user says they have Premium and want long-form. Long-form kills reach and reads like a blog; avoid it.
- Count characters per tweet and show the count. URLs count as ~23 characters regardless of length (t.co wrapping).

## Single post vs thread

Default to a **single post**. Use a thread only when the content genuinely needs sequence:
- A list of 3+ distinct points
- A step-by-step how-to
- A story with real beats
- A before/after with detail

If you can say it in one post, say it in one post. Padded threads read as engagement-bait.

## Thread rules

- **Tweet 1 is the hook** and must work alone — most people only see it. No "a thread 🧵" as a substitute for an actual hook (a small "🧵" or "1/" marker is fine *after* a real hook).
- One idea per tweet. Each should be semi-readable out of context.
- Number tweets `1/`, `2/`, … or `1/n` if the count is known.
- Keep momentum: end early tweets on a slight cliffhanger where natural.
- Final tweet: the takeaway + one light CTA (a question, or "follow for more" if it fits the voice). Put the source link here or in a reply, not in the hook (links in the first tweet suppress reach).

## Style

- More direct and opinionated than LinkedIn. Take a stance.
- **Hashtags: 0–2 max**, and usually 0. No hashtag blocks.
- Emojis: sparing. Never as bullet markers in a row. A single one for tone is okay if the voice profile allows.
- Lowercase / casual is fine if that's the author's voice — defer to `voice-profile.md`.
- No "RT if you agree," no follower-baiting clichés.

## Hard rules

- Never fabricate numbers, quotes, or outcomes (see `human-voice-rules.md`).
- Attribute claims from a research source to that source.
- Stay within the character limit on every tweet — a post that's 3 characters over is broken.
